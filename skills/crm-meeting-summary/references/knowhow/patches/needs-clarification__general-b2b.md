# Scenario x Industry Patch: 需求澄清 x 通用企业服务

版本: `v1`

## Extra attention points
- 确认当前痛点是否具备组织级优先级，而不只是局部团队抱怨
- 检查 success criteria 是否经得起 procurement 与跨团队评审
- 区分 user enthusiasm 与 buying readiness
- 如果某位参与者重复提到 implementation cost、service quality 或 pricing 旧问题，要将其上升为可能影响交易路径的因素，而不是随口一提

## High-value prompts for judgment
- 这个问题是否重要到足以争夺当前预算？
- 客户是在验证根因，还是只是在没有购买纪律的前提下收集想法？
- 我们看到的是通往 pilot/next stage 的路径，还是仅仅礼貌性延续？
